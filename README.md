# Kissel's Bath and Kitchen — Website

Production website for **Kissel's Bath and Kitchen**, a family-owned bathroom & kitchen
remodeling company serving the Denver metro area (based in Aurora, CO).

- **Stack:** [Astro](https://astro.build) (static site generation) + Tailwind CSS + Decap CMS
- **Hosting:** Netlify (build command `npm run build`, publish dir `dist`)
- **Production URL:** https://kisselremodeling.com

## Quick start

```bash
npm install
npm run dev        # local dev server (accepts --port / --host, e.g. npm run dev -- --port 7100)
npm run build      # production build → dist/
npm run preview    # preview the production build locally
```

Requires Node 20+.

## Editing content (Decap CMS)

All site copy lives in Git-tracked content files — no database. There are two ways to edit:

### 1. Directly in the repo

| Content            | Location                     |
| ------------------ | ---------------------------- |
| Site settings (phone, email, hours, service areas, rating) | `src/data/settings.json` |
| Services (10)      | `src/content/services/*.md`  |
| Testimonials (6)   | `src/content/testimonials/*.md` |
| FAQ (18)           | `src/content/faq/*.md`       |
| Portfolio (6)      | `src/content/portfolio/*.md` |
| Home hero / About story | `src/content/pages/*.md` |

Astro reads these files at build time via
[content collections](https://docs.astro.build/en/guides/content-collections/)
(schemas in `src/content/config.ts`), so every edit changes the site after rebuild.

### 2. Via the admin panel (`/admin`)

The site ships with [Decap CMS](https://decapcms.org) at `/admin`
(`public/admin/index.html` + `public/admin/config.yml`), configured with the
`git-gateway` backend. To enable it on the deployed site:

1. In Netlify: **Site settings → Identity → Enable Identity**.
2. **Identity → Services → Git Gateway → Enable**.
3. Invite users under **Identity → Invite users**.
4. Visit `https://kisselremodeling.com/admin` and log in.

For local content editing without deploying:

```bash
npx decap-server   # then open http://localhost:4321/admin/ while `npm run dev` runs
```

`local_backend: true` is already set in `public/admin/config.yml`.
To enable draft → review → publish, uncomment `publish_mode: editorial_workflow`
in that file.

Media uploaded through the CMS is stored in `public/images/uploads/` and served
from `/images/uploads/`.

## Contact form

The estimate form on `/contact` uses
[Netlify Forms](https://docs.netlify.com/forms/setup/) (`data-netlify="true"` +
`netlify-honeypot`). It is detected automatically at deploy time — submissions
appear under **Netlify → Forms → estimate**. It does **not** collect submissions
in local development.

## Project structure

```
site/
├── astro.config.mjs        # site URL, Tailwind + sitemap integrations
├── tailwind.config.mjs     # brand palette (#0f172a / #475569 / #94a3b8 / #d97706 / #f8fafc)
├── netlify.toml            # build settings + security headers
├── public/
│   ├── admin/              # Decap CMS (index.html + config.yml)
│   ├── images/             # hero, service, portfolio, OG images
│   ├── robots.txt
│   └── favicon.svg
└── src/
    ├── content/            # CMS-editable content collections (see table above)
    │   └── config.ts       # collection schemas (Zod)
    ├── data/settings.json  # global business info (CMS-editable)
    ├── layouts/BaseLayout.astro   # SEO head: canonical, OG, Twitter, JSON-LD
    ├── components/         # Header, Footer, ServiceCard, TestimonialCard, CTASection, Stars
    ├── lib/seo.ts          # JSON-LD builders (LocalBusiness, OfferCatalog, FAQPage, BreadcrumbList)
    ├── pages/              # /, /services, /pricing, /portfolio, /about, /faq,
    │                       # /contact, /thank-you, /404
    └── styles/global.css   # Tailwind directives + small custom CSS
```

## SEO notes

- Canonical URL, Open Graph, and Twitter cards on every page via `BaseLayout.astro`.
- Per-page JSON-LD: `HomeAndConstructionBusiness` sitewide, `Service` + `OfferCatalog`
  on /services, `OfferCatalog` on /pricing, `FAQPage` (all 18 Q&As) on /faq,
  `BreadcrumbList` on inner pages, `Review` items embedded in the business schema
  on / and /about.
- `sitemap-index.xml` generated by `@astrojs/sitemap`; `robots.txt` allows all and
  points to the sitemap.
- Inter is self-hosted via `@fontsource/inter` (no Google Fonts CDN).
- `/thank-you` and `/404` are `noindex`.

## Deployment

Push to the connected Git branch — Netlify builds with `npm run build` and
publishes `dist/`. Node version is pinned to 20 in `netlify.toml`.
